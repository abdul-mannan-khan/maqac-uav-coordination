Result 1 · Theorem 3

Value without a service order

A service event e = (UAV i, cell c, arrival time τ) carries its own arrival time. A user’s value is its survival at the earliest event that covers it:

f(X) = Σⱼ wⱼ · max Sⱼ(τₑ)

max over the events in X that cover user j; w = priority, S = session survival

Monotone submodular for any non-increasing survival function

No fixed service order: holds when UAVs choose at the same time and footprints overlap

Equal in expectation to the score we measure

Checked in 20,000 random trials with arbitrary order and overlap: no violation (Supplementary Table S2)

The submodularity argument itself is standard: f is a weighted coverage function. The contribution is the modelling step. Order-dependent formulations need a centralized search over sequences; here the arrival time is part of the element, so adding one UAV's event cannot change another's value.
